================================================================
  NOTEBOOKMIND — HOW TO START
================================================================

QUICK START
-----------
1. Open PowerShell in the project folder:
      cd C:\Users\yunes\Desktop\PI

2. Run:
      .\start.ps1

   This script automatically:
   • Syncs the latest built extension to JupyterLab
   • Sets all API keys (Gemini, Supabase)
   • Starts JupyterLab

3. Open the URL shown in the terminal (copy it — it includes a token):
      http://localhost:8888/lab?token=...
   (Port may be 8889 or 8890 if 8888 is already used — check terminal output)

4. The NotebookMind LOGIN SCREEN appears as an overlay automatically.
   Sign in with your Supabase email/password. (With no backend configured it
   falls back to demo mode, where any email/password is accepted.)


OPENING THE PLUGIN
------------------
• The login overlay appears automatically on load.
• To reopen after closing: Command Palette (Ctrl+Shift+C) →
  search "NotebookMind" → "Open NotebookMind"


================================================================
  AFTER ANY CODE CHANGE — HOW TO REBUILD
================================================================

Run these 3 commands in order:

  1. npx tsc --sourceMap
          (compiles TypeScript → lib/)

  2. .\venv\Scripts\python.exe -m jupyter labextension build --development True .
          (bundles lib/ → notebookmind/labextension/static/)

  3. .\start.ps1
          (syncs the build + restarts JupyterLab)

IMPORTANT: JupyterLab loads the extension from:
  C:\Users\yunes\AppData\Roaming\Python\share\jupyter\labextensions\notebookmind\
start.ps1 automatically copies the new build there on every launch.
